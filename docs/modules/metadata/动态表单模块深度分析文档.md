## 一、项目概述

### 1.1 项目定位

**Sky-Web** 是一个基于 **Vue 3 + TypeScript + Vite** 的元数据驱动的低代码前端框架，配合 Sky-Server 后端使用。其核心思想是通过数据库中的元数据配置动态生成表单、列表、权限控制等UI组件，无需硬编码即可快速构建业务系统。

### 1.2 技术栈

| 技术 | 版本/说明 |
|------|----------|
| 框架 | Vue 3 (Composition API) |
| 语言 | TypeScript |
| UI组件库 | Arco Design Vue |
| 状态管理 | Pinia |
| 构建工具 | Vite |
| HTTP客户端 | Axios |

### 1.3 与后端的关系

- **Sky-Server** 提供元数据API和数据CRUD接口
- 元数据表 (`sys_table`, `sys_column`, `sys_dict` 等) 存储在数据库中
- 前端通过API获取元数据配置，动态渲染UI

```typescript
  tableName: string,
  params?: Partial<PageRequest>

  const requestBody = {
    tableName,
    page: params?.page || 1,
    pageSize: params?.pageSize || 15,

    total: data.data.total || data.data.Total || 0,
    page: data.data.page || data.data.Page || 1,
    pageSize: data.data.pageSize || data.data.PageSize || 20
```

### 3.3 状态管理层 (`stores/`)

#### 3.3.1 useMetadataStore - 元数据缓存

这是整个元数据系统的核心 Store，负责缓存表配置、字段配置等元数据。

```typescript
export const useMetadataStore = defineStore('metadata', () => {
  // 状态
  const subsystems = ref<Subsystem[]>([])
  const subsystemsLoaded = ref(false)
  const tableCategories = ref<Map<number, TableCategory[]>>(new Map())
  const tables = ref<Map<number, SysTable[]>>(new Map())
  const tableConfigs = ref<Map<number, TableConfig>>(new Map())
  const columns = ref<Map<number, SysColumn[]>>(new Map())
  const loading = ref({
    subsystems: false,
    categories: false,
    tables: false,
    config: false
  })

  // 计算属性
  const activeSubsystems = computed(() => {
    return subsystems.value
      .filter(s => s.IS_ACTIVE === 'Y')
      .sort((a, b) => (a.ORDERNO || 0) - (b.ORDERNO || 0))
  })

  const subsystemTree = computed<TreeNode[]>(() => {
    // 构建子系统-类别-表的树形结构
    return activeSubsystems.value.map(subsystem => ({
      key: `subsystem-${subsystem.ID}`,
      title: subsystem.SUBSYSTEM_NAME,
      type: 'subsystem',
      children: [...]
    }))
  })

  // Actions
  async function loadSubsystems(force = false): Promise<Subsystem[]> {
    if (subsystemsLoaded.value && !force) {
      return subsystems.value
    }
    loading.value.subsystems = true
    try {
      const result = await api.fetchSubsystems()
      subsystems.value = result.list
      subsystemsLoaded.value = true
      return result.list
    } finally {
      loading.value.subsystems = false
    }
  }

  async function loadTableConfig(tableId: number, force = false): Promise<TableConfig> {
    // 检查缓存
    if (tableConfigs.value.has(tableId) && !force) {
      return tableConfigs.value.get(tableId)!
    }

    loading.value.config = true
    try {
      const config = await api.fetchTableConfig(tableId)

      // 解析扩展属性
      if (config.table.PROPS) {
        try {
          config.props = JSON.parse(config.table.PROPS)
        } catch {
          config.props = {}
        }
      }

      // 适配字段名
      config.columns = config.columns.map(adaptColumn)

      // 处理子表配置
      if (config.childTables) {
        config.childTables = config.childTables.map(...)
      }

      // 缓存配置
      tableConfigs.value.set(tableId, config)
      columns.value.set(tableId, config.columns)

      return config
    } finally {
      loading.value.config = false
    }
  }

  function getTableConfig(tableId: number): TableConfig | undefined {
    return tableConfigs.value.get(tableId)
  }

  function getVisibleColumns(tableId: number): SysColumn[] {
    return getTableColumns(tableId)
      .filter(c => {
        const isVisible = c.IS_VISIBLE || (c as any).isVisible
        if (isVisible !== undefined && isVisible !== 'Y') return false
        const isActive = c.IS_ACTIVE || (c as any).isActive
        if (isActive !== undefined && isActive !== 'Y') return false
        return true
      })
      .sort((a, b) => (a.ORDERNO || 0) - (b.ORDERNO || 0))
  }

  function getGridColumns(tableId: number): SysColumn[] {
    return getVisibleColumns(tableId).filter(c => {
      // 检查字段 MASK 的第 5 位（索引 4）：列表可见
      const mask = c.MASK || (c as any).mask
      if (mask && mask.length >= 5) {
        return mask[4] === '1'
      }

      // 如果没有 MASK，检查是否有列宽配置
      const gridWidth = c.GRID_WIDTH || (c as any).displayCols
      if (gridWidth && gridWidth > 0) return true

      // 系统字段默认不显示
      const systemFields = ['ID', 'CREATE_BY', 'CREATE_TIME', ...]
      if (systemFields.includes(c.DB_NAME)) return false

      return true
    })
  }

  function clearCache() {
    subsystems.value = []
    subsystemsLoaded.value = false
    tableCategories.value.clear()
    tables.value.clear()
    tableConfigs.value.clear()
    columns.value.clear()
  }

  return {
    // 状态
    subsystems,
    tableConfigs,
    columns,
    loading,

    // 计算属性
    subsystemTree,

    // 方法
    loadSubsystems,
    loadTableConfig,
    getTableConfig,
    getVisibleColumns,
    getGridColumns,
    clearCache
  }
})
```

**缓存策略**：
- 首次加载后缓存到 Map
- 重复调用直接返回缓存
- 可通过 `force=true` 强制刷新

#### 3.4.1 useDynamicForm - 动态表单核心逻辑

这是动态表单的核心逻辑封装，处理表单的加载、验证、提交等流程。

```typescript
export function useDynamicForm(tableId: number, mode: FormMode = 'view') {
  const metadataStore = useMetadataStore()
  const formStore = useDynamicFormStore()

  // 状态
  const loading = ref(false)
  const submitting = ref(false)
  const tableConfig = ref<TableConfig | null>(null)
  const formData = ref<FormData>({})
  const originalData = ref<FormData>({})  // 保存原始数据用于对比变更
  const errors = ref<Record<string, string>>({})

  // 计算属性
  const formColumns = computed(() => {
    if (!tableConfig.value) return []
    return tableConfig.value.columns
      .filter(c => {
        // 检查是否激活
        const isActive = c.IS_ACTIVE || (c as any).isActive
        if (isActive !== undefined && isActive !== 'Y') return false

        // 根据 MASK 和模式过滤字段
        const mask = c.MASK || (c as any).mask
        if (mask && mask.length >= 4) {
          if (mode === 'create' && mask[0] !== '1') return false
          if (mode === 'edit' && mask[2] !== '1') return false
        }
        return true
      })
      .sort((a, b) => (a.ORDERNO || 0) - (b.ORDERNO || 0))
  })

  const requiredFields = computed(() => {
    return formColumns.value
      .filter(c => c.NULL_ABLE === 'N')
      .map(c => c.DB_NAME)
  })

  const isReadonly = computed(() => mode === 'view')

  const canSave = computed(() => {
    if (mode === 'view') return false
    if (!tableConfig.value) return false
    const mask = tableConfig.value.table.MASK || ''
    if (mode === 'create') return mask.includes('A')
    if (mode === 'edit') return mask.includes('M')
    return false
  })

  // 核心方法
  async function loadTableConfig(): Promise<TableConfig> {
    loading.value = true
    try {
      formStore.reset()
      tableConfig.value = await metadataStore.loadTableConfig(tableId)
      initFormData()
      return tableConfig.value
    } catch (error) {
      Message.error('加载表单配置失败')
      throw error
    } finally {
      loading.value = false
    }
  }

  function initFormData() {
    if (!tableConfig.value) return
    const data: FormData = {}

    formColumns.value.forEach(column => {
      const dbName = column.DB_NAME || (column as any).dbName
      const defaultValue = column.DEFAULT_VALUE || (column as any).defaultValue

      // 优先使用字段配置的默认值
      if (defaultValue) {
        data[dbName] = defaultValue
      } else {
        // 检查是否有字典默认值
        const sysDictId = column.SYS_DICT_ID || (column as any).sysDictId
        if (sysDictId && tableConfig.value?.dictData) {
          const dictItems = tableConfig.value.dictData[Number(sysDictId)]
          const defaultItem = dictItems?.find(item =>
            (item.IS_DEFAULT_VALUE || (item as any).isDefaultValue) === 'Y'
          )
          if (defaultItem) {
            data[dbName] = defaultItem.VALUE || (defaultItem as any).value
          } else {
            data[dbName] = null
          }
        } else {
          data[dbName] = null
        }
      }
    })

    formData.value = data
  }

  async function loadRecordData(recordId: number): Promise<FormData> {
    if (!tableConfig.value) await loadTableConfig()

    loading.value = true
    try {
      const tableName = tableConfig.value!.table.TABLE_NAME || tableConfig.value!.table.NAME
      const record = await formStore.loadRecord(tableName, recordId)

      // 保存原始数据（深拷贝）
      originalData.value = JSON.parse(JSON.stringify(record))
      formData.value = { ...record }

      return record
    } catch (error) {
      Message.error('加载数据失败')
      throw error
    } finally {
      loading.value = false
    }
  }

  function validateField(column: SysColumn, value: any): string | null {
    const nullAble = column.NULL_ABLE || (column as any).nullAble
    const displayName = column.DISPLAY_NAME || (column as any).displayName || column.DB_NAME
    const errorMsg = column.ERROR_MSG || (column as any).errorMsg
    const regExpression = column.REG_EXPRESSION || (column as any).regExpression
    const colType = column.COL_TYPE || (column as any).colType
    const colLength = column.COL_LENGTH || (column as any).colLength

    // 必填验证
    if (nullAble === 'N') {
      if (value === null || value === undefined || value === '') {
        // 编辑模式下，如果原始值也是空，不报错
        if (mode === 'edit') {
          const orig = originalData.value[column.DB_NAME]
          if (orig === null || orig === undefined || orig === '') return null
        }
        return errorMsg || `${displayName}不能为空`
      }
    }

    // 如果值为空且非必填，跳过后续验证
    if (value === null || value === undefined || value === '') return null

    // 数据类型验证
    const typeError = validateDataType(colType, value, displayName, colLength)
    if (typeError) return typeError

    // 正则表达式验证
    if (regExpression && value) {
      try {
        const regex = new RegExp(regExpression)
        if (!regex.test(String(value))) {
          return errorMsg || `${displayName}格式不正确`
        }
      } catch {
        console.error('Invalid regex:', regExpression)
      }
    }

    return null
  }

  function validateForm(): boolean {
    const newErrors: Record<string, string> = {}

    formColumns.value.forEach(column => {
      const value = formData.value[column.DB_NAME]
      // 编辑模式下跳过不在 formData 中的字段
      if (mode === 'edit' && !(column.DB_NAME in formData.value)) return
      const error = validateField(column, value)
      if (error) newErrors[column.DB_NAME] = error
    })

    errors.value = newErrors
    return Object.keys(newErrors).length === 0
  }

  function setFieldValue(fieldName: string, value: any) {
    formData.value[fieldName] = value
    // 清除该字段的错误
    delete errors.value[fieldName]
  }

  function getChangedFields(): FormData {
    const changedFields: FormData = {}
    for (const key in formData.value) {
      const currentValue = formData.value[key]
      const originalValue = originalData.value[key]
      if (!isEqual(currentValue, originalValue)) {
        changedFields[key] = currentValue
      }
    }
    return changedFields
  }

  async function submitForm(): Promise<FormData | undefined> {
    if (!validateForm()) {
      Message.error('请检查表单填写')
      return
    }

    if (!tableConfig.value) {
      Message.error('表单配置未加载')
      return
    }

    submitting.value = true
    try {
      const tableName = tableConfig.value.table.TABLE_NAME || tableConfig.value.table.NAME
      const pkField = tableConfig.value.table.PK || 'ID'

      let result: FormData
      if (mode === 'create') {
        result = await formStore.createRecord(tableName, formData.value)
        Message.success('创建成功')
      } else if (mode === 'edit') {
        const recordId = formData.value[pkField] as number
        const changedFields = getChangedFields()
        result = await formStore.updateRecord(tableName, recordId, changedFields)
        Message.success('更新成功')
      } else {
        throw new Error('当前模式不支持保存')
      }

      formData.value = { ...result }
      return result
    } catch (error) {
      Message.error('保存失败')
      throw error
    } finally {
      submitting.value = false
    }
  }

  async function submitFormWithDetails(details: any[]): Promise<any> {
    if (!validateForm()) {
      Message.error('请检查表单填写')
      return
    }

    if (!tableConfig.value) {
      Message.error('表单配置未加载')
      return
    }

    submitting.value = true
    try {
      const tableName = tableConfig.value.table.TABLE_NAME || tableConfig.value.table.NAME
      const pkField = tableConfig.value.table.PK || 'ID'

      let mainRecord: Record<string, any>
      if (mode === 'edit') {
        mainRecord = getChangedFields()
        // 强制更新主表的修改时间
        const now = new Date()
        mainRecord.update_time = now.getFullYear() + '-' +
          String(now.getMonth() + 1).padStart(2, '0') + '-' +
          String(now.getDate()).padStart(2, '0') + ' ' +
          String(now.getHours()).padStart(2, '0') + ':' +
          String(now.getMinutes()).padStart(2, '0') + ':' +
          String(now.getSeconds()).padStart(2, '0')
      } else {
        mainRecord = { ...formData.value }
      }

      const result = await api.saveRecordWithDetails({
        tableName,
        mainRecord,
        details,
        mode: mode === 'edit' ? 'update' : mode,
        mainRecordId: mode === 'edit' ? (formData.value[pkField] as number) : undefined
      })

      formData.value = { ...result.mainRecord }
      Message.success('保存成功')
      return result
    } catch (error: any) {
      if (error.message && error.message.includes('没有字段被修改')) {
        Message.success('保存成功')
        return { mainRecord: formData.value, details }
      }
      Message.error('保存失败')
      throw error
    } finally {
      submitting.value = false
    }
  }

  function shouldShowField(column: SysColumn): boolean {
    // 如果没有配置显示控制，默认显示
    if (!column.SHOW_COLUMN_ID || !column.SHOW_COLUMN_VALUE) return true

    // 查找控制字段
    const controlColumn = formColumns.value.find(c => c.ID === column.SHOW_COLUMN_ID)
    if (!controlColumn) return true

    // 获取控制字段的值
    const controlValue = formData.value[controlColumn.DB_NAME]

    // 比较值（支持多个值，用逗号分隔）
    const expectedValues = column.SHOW_COLUMN_VALUE.split(',').map(v => v.trim())
    return expectedValues.includes(String(controlValue))
  }

  function isFieldReadonly(column: SysColumn): boolean {
    if (isReadonly.value) return true
    if (column.IS_READONLY === 'Y') return true

    const mask = column.MASK || (column as any).mask
    if (mask && mask.length >= 4) {
      if (mode === 'create' && mask[1] !== '1') return true
      if (mode === 'edit' && mask[3] !== '1') return true
    }

    return false
  }

  return {
    // 状态
    loading,
    submitting,
    tableConfig,
    formData,
    errors,

    // 计算属性
    formColumns,
    requiredFields,
    isReadonly,
    canSave,

    // 方法
    loadTableConfig,
    loadRecordData,
    validateField,
    validateForm,
    setFieldValue,
    getChangedFields,
    submitForm,
    submitFormWithDetails,
    shouldShowField,
    isFieldReadonly
  }
}
```

#### 3.4.2 useFieldRenderer - 字段渲染器逻辑

负责根据字段配置动态选择合适的渲染组件。

```typescript
// 字段类型到组件的映射
const FIELD_COMPONENT_MAP: Record<string, string> = {
  // 基础输入类
  text: 'TextField',
  textarea: 'TextareaField',
  number: 'NumberField',
  // ... 其他类型
}

export function useFieldRenderer(column: SysColumn, mode: FormMode = 'view') {
  const componentName = computed(() => {
    // 优先判断 SET_VALUE_TYPE（赋值方式）
    const setValueType = column.SET_VALUE_TYPE || (column as any).setValueType
    if (setValueType === 'fk') return 'ForeignKeyField'
    if (setValueType === 'select') return 'SelectField'

    // 特殊处理：系统时间字段
    const timeFields = ['CREATE_TIME', 'UPDATE_TIME', 'CREATED_AT', 'UPDATED_AT']
    if (timeFields.includes(column.DB_NAME)) return 'DatetimeField'

    // 优先使用 DISPLAY_TYPE
    const displayType = column.DISPLAY_TYPE || (column as any).displayType
    if (displayType) {
      const displayTypeMap: Record<string, string> = {
        text: 'TextField',
        textarea: 'TextareaField',
        number: 'NumberField',
        select: 'SelectField',
        // ... 其他类型
      }
      const mapped = displayTypeMap[displayType.toLowerCase()]
      if (mapped) return mapped
    }

    // 其次使用 CONTROL_TYPE
    const controlType = column.CONTROL_TYPE || (column as any).controlType
    if (controlType) {
      return FIELD_COMPONENT_MAP[controlType] || 'TextField'
    }

    return 'TextField'
  })

  const isReadonly = computed(() => {
    if (mode === 'view') return true
    if (column.IS_READONLY === 'Y') return true

    const mask = column.MASK || column.mask || ''
    if (mask && mask.length >= 4) {
      if (mode === 'create' && mask[1] !== '1') return true
      if (mode === 'edit' && mask[3] !== '1') return true
    }

    return false
  })

  const isRequired = computed(() => {
    const nullAble = column.NULL_ABLE || (column as any).nullAble
    return nullAble === 'N'
  })

  const placeholder = computed(() => {
    if (column.PLACEHOLDER) return column.PLACEHOLDER
    const displayName = column.DISPLAY_NAME || column.displayName || ''
    return displayName ? `请输入${displayName}` : ''
  })

  const helpText = computed(() => column.HELP_TEXT || '')

  const validationRules = computed(() => {
    const rules: any[] = []

    const nullAble = column.NULL_ABLE || (column as any).nullAble
    const displayName = column.DISPLAY_NAME || (column as any).displayName || column.DB_NAME
    const errorMsg = column.ERROR_MSG || (column as any).errorMsg
    const regExpression = column.REG_EXPRESSION || (column as any).regExpression

    // 必填规则
    if (nullAble === 'N') {
      rules.push({
        required: true,
        message: errorMsg || `${displayName}不能为空`
      })
    }

    // 正则规则
    if (regExpression) {
      try {
        const regex = new RegExp(regExpression)
        rules.push({
          pattern: regex,
          message: errorMsg || `${displayName}格式不正确`
        })
      } catch {
        console.error('Invalid regex:', regExpression)
      }
    }

    return rules
  })

  function formatValue(value: any): string {
    if (value === null || value === undefined || value === '') return '-'

    const displayType = column.DISPLAY_TYPE || (column as any).displayType
    const controlType = (displayType || column.CONTROL_TYPE || (column as any).controlType)?.toLowerCase()

    switch (controlType) {
      case 'date':
        return new Date(value).toLocaleDateString('zh-CN')
      case 'datetime':
        return new Date(value).toLocaleString('zh-CN')
      case 'number':
        if (column.DECIMAL_PRECISION !== undefined) {
          return Number(value).toFixed(column.DECIMAL_PRECISION)
        }
        return String(value)
      case 'checkbox':
      case 'switch':
        return value ? '是' : '否'
      default:
        return String(value)
    }
  }

  return {
    componentName,
    isReadonly,
    isRequired,
    placeholder,
    helpText,
    validationRules,
    formatValue
  }
}
```

### 3.5 组件层 (`components/`)

#### 3.5.1 DynamicForm - 动态表单主组件

**Props**:

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| tableId | number | - | **必填**，表单ID（sys_table.ID） |
| recordId | number | - | 记录ID（编辑/查看模式时需要） |
| copyFrom | number | - | 复制来源记录ID（新增模式） |
| mode | 'create' \| 'edit' \| 'view' | 'view' | 表单模式 |
| labelColSpan | number | 6 | 标签列宽度（24栅格） |
| wrapperColSpan | number | 18 | 输入列宽度（24栅格） |
| layout | 'horizontal' \| 'vertical' \| 'inline' | 'horizontal' | 布局方式 |
| rowGutter | number | 16 | 行间距（px） |
| showGroupTitle | boolean | true | 是否显示分组标题 |
| showSystemFields | boolean | true | 是否显示系统字段 |
| autoLabelWidth | boolean | false | 是否自动标签宽度 |

**Events**:

| 事件名 | 参数 | 说明 |
|--------|------|------|
| submit | (data: FormData) | 表单提交成功 |
| change | (field: string, value: any) | 字段值变化 |
| loaded | (config: TableConfig) | 表单配置加载完成 |

**Expose 方法**:

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| validate | - | Promise\<boolean\> | 手动触发表单验证 |
| getFormData | - | FormData | 获取表单数据 |
| setFormData | (data: FormData) | void | 设置表单数据 |
| reset | - | void | 重置表单 |
| getChangedFields | - | FormData | 获取变更的字段 |
| getChildTablesData | - | Record<string, any[]> | 获取子表数据 |
| validateChildTables | - | { valid: boolean; errors: string[] } | 验证子表数据 |

**核心功能**:

1. **字段分组**
   - 基础字段组（`ORDERNO <= 1000`）
   - 折叠字段组（通过 `PROPS.groups` 配置）
   - 系统字段组（`ORDERNO > 1000`）

2. **子表支持**
   - 1:1 子表（OneToOneChildTable）
   - 1:n 子表（OneToManyChildTable）
   - 内嵌编辑 / 弹出编辑 两种模式

3. **布局控制**
   - 通过 `SYS_OBJUICONF_ID` 控制列数（1/2/3/4 列）
   - 字段可通过 `DISPLAY_COLS` 跨列

4. **字段级显示控制**
   - MASK 权限控制
   - 级联显示（`SHOW_COLUMN_ID` / `SHOW_COLUMN_VALUE`）

**内部结构**:

```
DynamicForm
├── a-spin (loading状态)
└── a-form
    ├── 基础字段组
    │   └── a-row → a-col → DynamicFormItem
    ├── 折叠字段组
    │   └── a-collapse → a-collapse-item → a-row → a-col → DynamicFormItem
    ├── 子表区域
    │   ├── OneToOneChildTable (多个)
    │   └── OneToManyChildTable (支持多子表Tab切换)
    └── 系统字段组
        └── a-row → a-col → DynamicFormItem
```

**核心代码片段**:

```vue
              :parent-record-id="recordId"
            />

      <template v-if="systemFields.length > 0 && showSystemFields">

                :key="column.ID"

  const groups = tableConfig.value.props.groups

function getFieldColSpan(column: SysColumn): number {
  // 优先使用字段配置的 DISPLAY_COLS
  const displayCols = column.DISPLAY_COLS || (column as any).displayCols
  if (displayCols && displayCols > 1) {
    const objUiConfId = tableConfig.value?.table?.SYS_OBJUICONF_ID || 2
    let colWidth = 12
    switch (objUiConfId) {
      case 1: colWidth = 24; break
      case 2: colWidth = 12; break
      case 3: colWidth = 8; break
      case 4: colWidth = 6; break
    }
    return Math.min(displayCols * colWidth, 24)
  }

  // 根据表的 SYS_OBJUICONF_ID 计算默认列数
  const objUiConfId = tableConfig.value?.table?.SYS_OBJUICONF_ID || 2
  let defaultSpan = 12
  switch (objUiConfId) {
    case 1: defaultSpan = 24; break
    case 2: defaultSpan = 12; break
    case 3: defaultSpan = 8; break
    case 4: defaultSpan = 6; break
  }

  // 根据控件类型调整
  const displayType = column.DISPLAY_TYPE || (column as any).displayType
  const controlType = (displayType || column.CONTROL_TYPE || (column as any).controlType)?.toLowerCase()
  const fullWidthControls = ['textarea', 'json', 'richtext', 'clob', 'xml']
  if (fullWidthControls.includes(controlType)) return 24

  return defaultSpan
}
```

## 五、权限控制系统

### 5.1 表级权限 (SysTable.MASK)

`SysTable.MASK` 是一个10位字符串，各位含义:

| 位索引 | 含义 | 对应操作 |
|--------|------|----------|
| 0 | 新增可见 | 显示新增按钮 |
| 1 | 新增可编辑 | 新增时字段可编辑 |
| 2 | 修改可见 | 显示编辑按钮 |
| 3 | 修改可编辑 | 编辑时字段可编辑 |
| 4 | 列表可见 | 列表页显示该表 |
| 5 | 列表可编辑 | 列表页可编辑 |
| 6 | 提交 | 提交操作 |
| 7 | 反提交 | 反提交操作 |
| 8 | 作废 | 作废操作 |
| 9 | 保留 | - |

**示例**:
- `"1111111000"` - 有前6项权限
- `"1111000000"` - 只有新增、编辑权限

**使用代码**:
```typescript
const canSave = computed(() => {
  if (mode === 'view') return false
  if (!tableConfig.value) return false
  const mask = tableConfig.value.table.MASK || ''
  if (mode === 'create') return mask.includes('A') // 或者检查第0/1位
  if (mode === 'edit') return mask.includes('M')   // 或者检查第2/3位
  return false
})
```

### 5.2 字段级权限 (SysColumn.MASK)

同样使用10位掩码，控制字段在不同场景下的可见性和可编辑性。

```typescript
const isFieldReadonly = computed(() => {
```

## 六、子表关系处理

### 6.1 关系定义

通过 `SysTable.SYS_PARENT_TABLE_ID` 定义父子表关系，`sys_table_ref` 表定义关系详情:

| 字段 | 含义 |
|------|------|
| ASSOCTYPE | 关联类型：`'1'` (1:1) 或 `'n'` (1:n) |
| REF_COLUMN_ID | 子表中外键字段ID |
| EDIT_TYPE | 编辑模式：`'Y'` (内嵌) 或 `'NP'` (弹出) |
| DISPLAY_NAME | 关系显示名称 |

### 6.2 1:1 子表处理

- 子表有一个外键字段指向主表
- 主表记录ID = 子表外键值
- 查询：`WHERE {ref_column} = {main_record_id}`
- 保存：通过 `saveRecordWithDetails` 同时提交

```typescript
async function getOneToOneChildTableRecord(childTable: any): Promise<any> {
  if (props.mode === 'create') return undefined
  if (!props.recordId) return undefined

  // 找到子表中引用父表的外键字段
  let refColumn = childTable.columns.find((col: any) => {
    const refTableId = col.REF_TABLE_ID || col.refTableId
    return refTableId === props.tableId
  })

  if (!refColumn) {
    const refColumnId = childTable.ref.refColumnId || childTable.ref.REF_COLUMN_ID
    refColumn = childTable.columns.find((col: any) => {
      const colId = col.ID || col.id
      return colId === refColumnId
    })
  }

  if (!refColumn) return undefined

  const refColumnDbName = getColumnDbName(refColumn)

  // 构建过滤条件
  const filters: Record<string, any> = {
    [refColumnDbName]: props.recordId
  }

  const childTableName = getTableName(childTable.table)

  // 调用 API 查找子表记录
  const response = await api.fetchRecords(childTableName, {
    filters,
    page: 1,
    pageSize: 1
  })

  if (response.list && response.list.length > 0) {
    return response.list[0]
  }

  return undefined
}
```

### 6.3 1:n 子表处理

- 子表有多个记录关联到主表
- 外键字段存储主表ID
- 支持内嵌编辑或弹出编辑
- 新增主表时：先保存主表，获取ID后才能新增子表

## 七、级联显示机制

通过 `SysColumn` 的两个字段实现字段间的级联显示:

```typescript
{
  SHOW_COLUMN_ID: number,       // 控制字段ID
  SHOW_COLUMN_VALUE: string     // 控制字段值（逗号分隔多个值）
}
```

**实现逻辑**:

```typescript
function shouldShowField(column: SysColumn): boolean {
  // 如果没有配置显示控制，默认显示
  if (!column.SHOW_COLUMN_ID || !column.SHOW_COLUMN_VALUE) {
    return true
  }

  // 查找控制字段
  const controlColumn = formColumns.value.find(c => c.ID === column.SHOW_COLUMN_ID)
  if (!controlColumn) return true

  // 获取控制字段的值
  const controlValue = formData.value[controlColumn.DB_NAME]

  // 比较值（支持多个值，用逗号分隔）
  const expectedValues = column.SHOW_COLUMN_VALUE.split(',').map(v => v.trim())
  return expectedValues.includes(String(controlValue))
}
```

**使用示例**:
```sql
-- 当 TYPE 字段值为 'custom' 时才显示此字段
UPDATE sys_column
SET SHOW_COLUMN_ID = 123,           -- TYPE 字段的 ID
    SHOW_COLUMN_VALUE = 'custom'
WHERE ID = 456;

-- 支持多个值（逗号分隔）
UPDATE sys_column
SET SHOW_COLUMN_ID = 123,
    SHOW_COLUMN_VALUE = 'custom,special'
WHERE ID = 456;
```

```vue
  return '查看'
})

const canEdit = computed(() => {
  return true // 根据权限判断
})

async function handleSave() {
  const isValid = await formRef.value.validate()
  if (!isValid) {
    Message.error('请检查表单填写')
    return
  }

  submitting.value = true
  try {
    await formRef.value.submit()
  } finally {
    submitting.value = false
  }
}

function handleSubmit(data: any) {
  Message.success('保存成功')
  if (mode.value === 'create' && data.ID) {
    router.replace({
      name: 'MetadataFormEdit',
      params: { tableId: tableId.value, id: data.ID }
    })
  } else {
    router.back()
  }
}

async function handleCancel() {
  const confirmed = await Modal.confirm({
    title: '确认取消',
    content: '确定要取消编辑吗？未保存的数据将丢失。'
  })
  if (confirmed) {
    if (mode.value === 'create') {
      router.back()
    } else {
      mode.value = 'view'
    }
  }
}
</script>
```

## 十、关键设计模式

### 10.1 元数据驱动模式

整个系统的核心思想：用数据描述UI，而非代码编写UI。

### 10.2 Composables 组合式函数

将逻辑与UI分离，便于复用和测试。

```
┌─────────────────────────────────────┐
│ Vue 组件 (UI)                       │
│  DynamicForm / DynamicTable         │
└────────────────┬────────────────────┘
                 │
                 ↓
┌─────────────────────────────────────┐
│ Composables (逻辑)                  │
│  useDynamicForm / useFieldRenderer  │
└────────────────┬────────────────────┘
                 │
                 ↓
┌─────────────────────────────────────┐
│ Stores (状态)                       │
│  useMetadataStore                   │
└────────────────┬────────────────────┘
                 │
                 ↓
┌─────────────────────────────────────┐
│ API (数据)                          │
│  metadata.ts                        │
└─────────────────────────────────────┘
```

### 10.3 策略模式（字段渲染）

通过 `useFieldRenderer` 根据不同字段类型选择不同渲染策略。

### 10.4 缓存模式

通过 Pinia Store 缓存元数据配置，避免重复请求。

### 10.5 适配器模式

通过 `adapter.ts` 处理前后端字段名不匹配问题。

## 十一、扩展点

### 11.1 新增字段类型

步骤:
1. 在 `components/FieldRenderers/` 下新建渲染组件
2. 在 `useFieldRenderer.ts` 的映射表中添加
3. 在 `DynamicFormItem.vue` 中异步导入并添加到 `COMPONENT_MAP`

**示例**: 新增 `BarcodeField` 条码字段

```typescript
// useFieldRenderer.ts
const FIELD_COMPONENT_MAP: Record<string, string> = {
  // ... 现有类型
  barcode: 'BarcodeField'
}

// DynamicFormItem.vue
const BarcodeField = defineAsyncComponent(() => import('../FieldRenderers/BarcodeField.vue'))
const COMPONENT_MAP: Record<string, any> = {
  // ... 现有映射
  BarcodeField
}
```

### 11.3 自定义验证规则

在 `useDynamicForm.ts` 的 `validateField` 中添加自定义验证逻辑。

```typescript
function validateField(column: SysColumn, value: any): string | null {
  // ... 现有验证

  // 自定义验证
  if (column.DB_NAME === 'PHONE') {
    if (!/^1[3-9]\d{9}$/.test(String(value))) {
      return '请输入正确的手机号'
    }
  }

  return null
}
```

## 十二、总结

Sky-Web 动态表单模块是一个**设计优雅、功能完整**的元数据驱动前端框架，其核心优势:

1. **低代码** - 通过配置而非编码生成业务表单
2. **高复用** - 一套组件支持所有业务表
3. **灵活** - 支持复杂的权限控制、级联显示、主从关系
4. **完整** - 覆盖列表-表单-查询-导入导出全流程
5. **可扩展** - 架构清晰，易于扩展新字段类型和功能

这套系统适合需要快速开发大量CRUD表单的企业级应用场景。
