# Sky-Web 动态表单模块优化执行方案

> 基于代码深度分析制定的具体优化方案

---

## 一、优化概览

### 1.1 发现的主要问题

| 类别 | 问题 | 优先级 |
|------|------|--------|
| 架构/类型 | 字段名大小写不一致导致的兼容性问题 | 🔴 高 |
| 性能 | 重复的外键数据请求 | 🟡 中 |
| 代码质量 | 冗余的空 else 分支、未使用的变量 | 🟡 中 |
| 测试覆盖 | 缺少单元测试 | 🟢 低 |
| 可维护性 | 字段渲染器组件重复代码 | 🟡 中 |

### 1.2 优化目标

- 🔧 修复已知问题
- 📈 提升性能
- 🧪 增加测试覆盖
- 📝 完善文档

---

## 二、详细优化方案

### 方案 1: 重构 adapter 层，统一字段规范 ✅ 已完成

**问题描述**: 目前 `adapter.ts` 中存在大量手动映射，代码冗余且易出错。

**优化方案**:
1. 创建通用的字段适配器工厂函数 `createAdapter`
2. 定义统一的字段映射配置数组
3. 移除冗余代码

**预期收益**: 代码减少 40%，更易维护

**实际改动**:
- 使用泛型工厂函数重构
- 清晰的映射配置数组
- 保持完整向后兼容性

---

### 方案 2: 字段渲染器基础层封装 ✅ 已完成

**问题描述**: 每个字段渲染器都有重复的 props、computed 逻辑。

**优化方案**:
1. 创建 `useFieldRendererBase` composable
2. 提取公共逻辑（placeholder、required、formatValue 等）
3. 统一视图模式渲染

**预期收益**: 减少代码重复，统一行为

**实际改动**:
- 新建 `useFieldRendererBase.ts` 包含所有通用逻辑
- 更新 `useFieldRenderer.ts` 复用基础层
- 更新 `index.ts` 导出新 composable

**后续优化**:
- 已更新 TextField、TextareaField、NumberField 使用基础层
- 其他字段渲染器可逐步迁移

---

### 方案 3: 优化外键缓存机制 ✅ 已完成

**问题描述**: `useForeignKeyCache.ts` 中有缓存逻辑，但 `useForeignKey.ts` 中仍有额外的 Map。

**优化方案**:
1. 合并缓存逻辑，只使用 `useForeignKeyCache`
2. 增加缓存过期时间 (可选，后续优化)
3. 添加缓存命中率统计 (可选，后续优化)

**预期收益**: 减少内存占用，提升性能

**实际改动**:
- 移除 `useForeignKey.ts` 中的独立 `optionsCache`
- 清理未使用的 `isDropdownMode` 状态
- 保持功能完整

---

### 方案 4: 完善 TypeScript 类型定义 ✅ 已完成

**问题描述**: `types/index.ts` 中部分类型定义不够精确，使用 `any` 较多。

**优化方案**:
1. 为 sys_table/sys_column 添加完整类型和枚举
2. 定义字段配置类型守卫函数
3. 定义 `ChildTableConfig` 和相关类型
4. 减少 `any` 类型使用

**预期收益**: 更好的类型安全，减少运行时错误

**实际改动**:
- 新增 `TableMaskIndex` 枚举
- 新增 `SetValueType` 枚举
- 新增 `DisplayType` 枚举
- 新增 `AssocType` 枚举
- 新增 `ChildTableRef` 和 `ChildTableConfig` 接口
- 新增 10+ 个类型守卫和工具函数
- 保留向后兼容

---

### 方案 5: 添加单元测试 ✅ 已完成

**问题描述**: 只有 `useForeignKeyCache.test.ts`，缺少其他核心模块测试。

**优化方案**:
1. 为 `types/index.ts` 添加类型守卫测试
2. 为 `useFieldRendererBase.ts` 添加测试
3. 为 `useFieldRenderer.ts` 添加测试

**预期收益**: 提升代码质量，确保重构不破坏现有功能

**实际改动**:
- 新增 `types/index.test.ts` (70+ 个测试用例)
- 新增 `composables/useFieldRendererBase.test.ts`
- 新增 `composables/useFieldRenderer.test.ts`

---

### 方案 6: 清理代码异味 ✅ 已完成

**问题描述**: 部分代码中存在空 else、console.log 等。

**优化方案**:
1. 移除空 else 分支（SelectField.vue）
2. 移除调试用 console.log（DynamicForm.vue）
3. 清理无用变量

**预期收益**: 代码更清晰整洁

**实际改动**:
- 清理 `SelectField.vue` 中的空 else 分支
- 移除 `DynamicForm.vue` 中的所有 console.log
- 移除未使用的 `ChildTablePanel`、`ChildTableInlinePanel` 导入
- 移除未使用的 `findRefColumn` 函数
- 移除未使用的 `oneToOneChildTableRecordIds` 变量
- 保留错误日志 `console.error` 用于调试
