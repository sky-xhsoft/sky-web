### 1. TypeScript泛型

所有工具函数都使用了完整的泛型类型:

```typescript
export function debounce<T extends (...args: any[]) => any>(
  fn: T,
  delay: number
): (...args: Parameters<T>) => void
```

### 2. 高阶函数

工具函数都是高阶函数，支持函数组合:

```typescript
const optimizedFn = debounce(memoize(expensiveFn), 300)
```

### 3. 清理函数

所有副作用操作都返回清理函数:

```typescript
const cleanup = lazyLoadImages('.img')
// 使用完毕后
cleanup()
```

所有工具都支持自定义配置:

