# 直播域名管理前端页面使用说明

## 📁 已创建的文件

1. **`src/api/live.ts`** - 直播域名 API 接口
2. **`src/pages/LiveDomain.vue`** - 直播域名管理页面
3. **`src/router/index.ts`** - 已添加路由配置

## 🚀 访问方式

### 方式1: 直接访问 URL

启动前端项目后，直接访问：

```
http://localhost:5173/live/domains
```

### 方式2: 通过后端菜单配置（推荐）

在后端数据库的 `sys_menu` 表中添加菜单项：

```sql
INSERT INTO sys_menu (
  NAME,
  DISPLAY_NAME,
  PARENT_ID,
  TYPE,
  URL,
  ICON,
  ORDERNO,
  IS_ACTIVE,
  SYS_COMPANY_ID
) VALUES (
  'live_domains',
  '直播域名管理',
  NULL,  -- 或者指定父菜单ID
  'page',
  '/live/domains',
  'icon-live',
  100,
  'Y',
  1  -- 你的公司ID
);
```

添加后，菜单会自动出现在左侧导航栏中。

## 🎨 页面功能

### 1. 域名列表

- ✅ 显示所有域名
- ✅ 按类型筛选（全部/推流域名/播放域名）
- ✅ 显示域名状态（已启用/已禁用）
- ✅ 显示创建时间

### 2. 添加域名

点击右上角"添加域名"按钮：

- 输入域名（如：push.example.com）
- 选择域名类型：
  - 推流域名（用于推送直播流）
  - 播放域名（用于播放直播流）

### 3. 域名操作

每个域名支持以下操作：

- **启用** - 启用已禁用的域名
- **禁用** - 禁用已启用的域名
- **删除** - 删除域名（需要确认）

所有接口都在 `src/api/live.ts` 中定义：

```typescript
// 添加域名

// 查询域名列表
listDomains(domainType?: number)

// 查询域名信息
getDomain(domainName: string)

// 删除域名
deleteDomain(domainName: string)

// 启用域名
enableDomain(domainName: string)

// 禁用域名
forbidDomain(domainName: string)
```

## 🎯 使用流程

### 1. 启动前端项目

```bash
cd sky-web
npm install
npm run dev
```

### 2. 访问页面

浏览器打开：`http://localhost:5173/live/domains`

### 3. 添加域名

1. 点击右上角"添加域名"按钮
2. 输入域名（如：push.example.com）
3. 选择域名类型（推流域名或播放域名）
4. 点击"确定"

### 4. 管理域名

- 启用/禁用域名：点击对应按钮
- 删除域名：点击"删除"按钮并确认

## ⚠️ 注意事项

1. **域名格式**
   - 必须是有效的域名格式
   - 例如：push.example.com, live.yourdomain.com

2. **域名备案**
   - 添加的域名必须已完成 ICP 备案
   - 否则腾讯云会拒绝添加

3. **域名类型**
   - 推流域名：用于推送直播流（OBS、FFmpeg 等）
   - 播放域名：用于播放直播流（网页、APP 等）
   - 两种类型需要分别添加

4. **删除限制**
   - 删除域名前建议先禁用
   - 删除操作不可恢复

## 🔍 故障排查

### 问题1: 页面无法访问

**解决方案**:
- 检查前端是否正常启动
- 检查路由配置是否正确
- 检查是否已登录

### 问题2: API 调用失败

**解决方案**:
- 检查后端服务是否启动
- 检查 API 地址配置（src/config.ts）
- 检查腾讯云配置是否正确
- 查看浏览器控制台错误信息

### 问题3: 添加域名失败

**解决方案**:
- 检查域名格式是否正确
- 检查域名是否已备案
- 检查腾讯云 SecretID 和 SecretKey 是否配置
- 查看后端日志
