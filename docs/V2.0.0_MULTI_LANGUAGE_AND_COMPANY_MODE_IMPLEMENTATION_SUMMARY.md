## 数据架构说明

### SysLanguage 表结构
```
id                  - 主键
sys_company_id      - 公司ID（0为系统默认）
code                - 语言代码（zh-CN, en-US等）
name                - 语言名称
is_default          - 是否为默认语言（Y/N）
is_active           - 是否激活（Y/N）
create_by           - 创建人
create_time         - 创建时间
update_by           - 更新人
update_time         - 更新时间
```

### SysTranslation 表结构
```
id                  - 主键
sys_company_id      - 公司ID（0为系统默认）
key                 - 翻译键
language            - 语言代码
value               - 翻译值
module              - 所属模块
is_active           - 是否激活
create_by           - 创建人
create_time         - 创建时间
update_by           - 更新人
update_time         - 更新时间
```

### SysCompany 扩展字段
```
logo                - 公司Logo
address             - 公司地址
contact             - 联系人
phone               - 联系电话
email               - 联系邮箱
```

### SysCompanyConf 扩展字段
```
default_language    - 默认语言
timezone            - 时区
currency            - 货币
max_storage_size    - 最大存储大小
max_file_size       - 最大文件大小
max_files           - 最大文件数
```

## API接口说明

### 语言管理接口
- `GET /api/v1/languages` - 获取语言列表
- `GET /api/v1/languages/translations` - 获取翻译列表（支持分页和筛选）
- `GET /api/v1/languages/translations/{key}` - 获取单个翻译
- `POST /api/v1/languages/translations` - 添加翻译
- `PUT /api/v1/languages/translations/{id}` - 更新翻译
- `DELETE /api/v1/languages/translations/{id}` - 删除翻译
- `GET /api/v1/languages/translations/export` - 导出翻译（JSON）
- `POST /api/v1/languages/translations/import` - 导入翻译（JSON文件）

## 使用说明

### 1. 数据库初始化
```bash
mysql -u root -p skyserver < sqls/sys_language.sql
mysql -u root -p skyserver < sqls/sys_translation.sql
mysql -u root -p skyserver < sqls/alter_sys_company.sql
mysql -u root -p skyserver < sqls/alter_sys_company_conf.sql
mysql -u root -p skyserver < sqls/alter_sys_user.sql
```

### 2. 语言切换
- 在应用顶部导航栏点击语言下拉框选择语言
- 支持的语言：简体中文、English、日本語、한국어
- 语言选择会保存到localStorage，下次访问自动应用
- 也可以通过URL参数：`?lang=en-US`切换语言

### 3. 翻译管理
- 登录系统管理员账号
- 进入系统管理 > 翻译管理
- 可以添加、编辑、删除翻译
- 支持按语言、模块、翻译键搜索
- 支持导入/导出JSON格式的翻译文件

## 架构特点

1. **多租户支持** - 语言和翻译支持系统级别（company_id=0）和公司级别配置
2. **缓存优化** - 翻译数据缓存在Redis中，提升查询性能
3. **灵活切换** - 支持通过界面和URL参数切换语言
4. **导入导出** - 翻译管理支持JSON格式导入导出，便于翻译团队协作
5. **向后兼容** - 所有变更都是扩展式的，不影响现有功能
