# 分享功能使用指南

## 创建分享

### 1. 在云盘页面选择文件或文件夹

### 2. 点击"创建分享"按钮

### 3. 设置分享参数
- **有效期**: 1天、7天、30天或永久
- **访问密码**: 可选，建议设置以保护内容

### 4. 创建成功后会显示分享信息
- 分享链接
- 访问密码（如果设置了）
- 有效期

### 5. 复制分享链接和密码
点击"复制链接和密码"按钮，会自动复制以下格式的文本：
```
分享链接：http://localhost:3000/share/abc123
访问密码：xyz789
有效期至：2024-02-01 12:00:00
```

## 访问分享

### 方式一：直接在浏览器打开
1. 复制分享链接
2. 在浏览器地址栏粘贴
3. 按回车访问

### 方式二：点击"在新标签页打开"
在分享成功对话框中点击此按钮，会自动在新标签页打开分享链接

### 访问流程
1. 打开分享链接（如：`http://localhost:3000/share/abc123`）
2. 如果设置了密码，输入访问密码
3. 点击"访问分享"按钮
4. 验证成功后显示文件信息
5. 点击"下载文件"按钮下载

## 分享链接格式

```
http://localhost:3000/share/{分享码}
```

例如：
- `http://localhost:3000/share/abc123`
- `http://localhost:3000/share/xyz789`

## 使用 ShareSuccessDialog 组件

```vue
<template>
  <div>
    <!-- 创建分享按钮 -->
    <a-button @click="handleCreateShare">创建分享</a-button>

    <!-- 分享成功对话框 -->
    <ShareSuccessDialog
      v-model:visible="showSuccessDialog"
      :share-code="shareInfo.shareCode"
      :password="shareInfo.password"
      :expire-time="shareInfo.expireTime"
    />
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import ShareSuccessDialog from '@/modules/cloud/components/dialogs/ShareSuccessDialog.vue'
import { useCloudShare } from '@/modules/cloud/composables/useCloudShare'

const { createShare } = useCloudShare()

const showSuccessDialog = ref(false)
const shareInfo = ref({
  shareCode: '',
  password: '',
  expireTime: '',
})

async function handleCreateShare() {
  // 创建分享
  const share = await createShare(file, {
    shareType: 'password',
    password: 'abc123',
    expireDays: 7,
  })

  if (share) {
    // 显示成功对话框
    shareInfo.value = {
      shareCode: share.shareCode,
      password: share.password,
      expireTime: share.expireTime,
    }
    showSuccessDialog.value = true
  }
}
</script>
```

## 注意事项

1. **密码安全**: 分享创建后无法再次查看密码，请妥善保管
2. **有效期**: 过期后分享链接将自动失效
3. **下载次数**: 可以设置最大下载次数限制
4. **分享管理**: 可以在"我的分享"中查看和管理所有分享

## 常见问题

### Q: 创建分享后如何获取链接？
A: 创建成功后会自动显示 ShareSuccessDialog 对话框，包含完整的分享信息。

### Q: 如何测试分享功能？
A:
1. 创建一个分享
2. 复制分享链接
3. 在浏览器隐私模式/无痕模式中打开链接
4. 输入密码验证
5. 下载文件

### Q: 分享链接在哪里？
A: 分享链接格式为 `http://localhost:3000/share/{分享码}`，其中分享码是后端自动生成的唯一标识。

### Q: 可以修改已创建的分享吗？
A: 目前支持删除分享，修改功能需要调用 `updateShare` API。
